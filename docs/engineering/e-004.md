# E-004 Failure-path coverage

Status: READY
Prerequisites: contract integrity, execution record, provider router. Do not reconstruct them.
Base: `codessa-engineering-factory` @ `b5d918e`

## Objective

Add executable coverage for failure paths in the existing execution slice.

## Allowed scope

`tests/failure-paths.ts`, `scripts/verify-slice.sh`, and `docs/engineering/execution-roadmap.md` status only. A slice change is allowed only if a required failure is not representable.

## Forbidden scope

Frozen spec, freeze decision, MCGL, execution redesign, memory backend, OpenViking, provider architecture, completed queue items, and closed branches.

## Required behavior

A failed or incomplete execution is explicit. It does not create durable memory. It does not create a false commit. Model text is not an observation. A missing outcome is not an invented decision. `REJECT` and `QUARANTINE` do not promote.

## Acceptance

`npm run codessa:verify` passes, including the new failure-path tests and the existing slice tests.
