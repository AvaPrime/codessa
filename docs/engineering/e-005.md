# E-005 Observation capture

Status: trial
Base: `015382c`

## Objective

An execution obtains an observation only from a sourced record that is not the model output.

## Required behavior

An observation needs an id, a source, and content. Source `model` or `provider` is not an observation. Content equal to the model text is not an observation. A valid observation stays distinct from model output. A missing or rejected observation still blocks commit.

## Forbidden

Authority validation of the external outcome. MCGL. Substrate selection. Rebuilding E-001 through E-004.
